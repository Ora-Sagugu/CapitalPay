# 虚拟账户（Virtual Account, VA）功能概述

## 1. 定义

虚拟账户（VA）是基于银行 / 支付机构实体「伞形母账户」生成的专属**虚拟收款标识**，用于实现低成本本地化收款、自动资金归集与精准对账。它**不是实体银行卡，也不是独立存款账户**。

底层逻辑：在持牌机构的实体母账户（NostroAccount）下，通过系统映射生成多个独立虚拟子账号，以「账实分离」机制解耦资金流与信息流，借助低成本本地清算网络完成跨境收款。

两类形态：

- **VLA（Virtual Ledger Account）**：纯内部分类账记录，无对外银行账号形式。
- **VAV（Virtual Bank Account Number）**：对外呈现看似真实的银行账号（含本地路由码 / IBAN），是跨境收款的主流形态。

## 2. 核心功能

- **本地化收款**：为目标市场（美 / 欧 / 英 / 港 / 新等）提供本地银行收款信息（账号、Routing Number / IBAN），付款方通过 ACH、SEPA 等低成本本地清算网络转账，无需发起昂贵国际电汇。
- **资金自动归集**：各虚拟子账户流入的资金，后台自动汇总至持牌机构 / 企业的单一实体主账户，实现多币种、多来源资金的统一沉淀。
- **智能自动对账**：每个 VA 绑定特定客户、订单或业务场景，系统依据唯一虚拟账号自动识别付款方并匹配交易，无需人工核对流水备注。
- **多币种管理**：可生成 USD / EUR / GBP 等不同币种的虚拟账户资料，便于分币种归集并后续换汇或提现。
- **合规与风控隔离**：作为伞形账户下的子标识，不直接暴露企业真实主账号，降低信息泄露风险，并便于机构执行反洗钱（AML）监控。

## 3. 关键特性

- **本质区别**：VA 是一组「收款资料」（含账号、银行代码等），不可刷卡消费、无 CVV，仅用于收钱；区别于可消费的虚拟卡（Virtual Card）。
- **运作机制**：资金实际进入支付机构 / 银行的真实主账户，VA 号码仅作为记账标签用于区分归属，不支持直接取现或现金业务。

## 4. 适用场景

- 跨境电商平台回款
- B2B 外贸收款
- SaaS 订阅费收取
- 多子公司 / 多订单财务分账

## 5. 说明

VA 账户通常由跨境支付机构或银行提供。具体支持的币种、清算通道及提现规则，以服务商条款为准。
